ARCHIVED STORIES — old & alternate versions
============================================
Kept for reference, not loaded automatically. Each is still a complete, swappable
window.IDN_STORY (same shape as the active story.js) — to play one, copy it over the
top-level story.js and reload, e.g.:

  cp "stories/archive/clod-bathos.complex.story.js" "story.js"

These are also preserved in git history; this folder just keeps them visible.
